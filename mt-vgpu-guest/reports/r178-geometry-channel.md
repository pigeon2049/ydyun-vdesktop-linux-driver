# r178：几何/颜色通道落定——PMR 池内容 + 池代数（零硬件触碰）

- **结论**：几何与颜色走 PMR 池内容，不走 CCB/context/注解。5MB 池实转储（GDB 停 Submit3，地址逐轮现算）：`[0,3841)` 全零头 + `[3841,5246721)` 像素 `ff0000ff`×1310720 + 254B 零尾；`1310720 = 1280×1024`，行连续（span 恰等于 `W·H·4`，无 stride 填充）。64×64 复核：池 `20479 = 3841+16384+254`，头/尾常量不变——池代数 `pool = 3841 + W·H·4 + 254` 双尺寸精确成立。颜色 = 像素字（此处 `0xff0000ff`，UMD 经 CPU 写入）。源面池（`0x5003000/0x5004000` 同尺寸全零）与 fill 无需源一致。会话零触碰（离线 fabricated），无代码改动。

## 实测

1. 排除：CCB（39B 全指针/标志）、`0x89:0x8` IN（12B 仅句柄 `0x3001`/type 0）、`0x89:0x5`（IN 空）、注解（仅内存用途名）——几何颜色皆不在此。
2. 池转储：`UMD_TRAP=137:10` 停 Submit3，`dump memory` 取 `0x500d000` backing 全 5246975B（GDB 下地址跨轮稳定，已现算核对）。
3. 像素相位：`3840=00`，`ff0000ff` 流自 3841 起、止于 5246720（完整像素）；首字节 00 归为池共享填充（与 3841 常量头一致），表面按 `[3841, +W·H·4)` 解读。
4. 双尺寸验证：base `3841+5242880+254=5246975` ✓；64×64 `3841+16384+254=20479` ✓（tq-perf abort 在 Submit 前，但池分配/映射已完成，尺寸有效）。
5. 门禁复核 `check-offline` 全绿（274+272）；会话 ref 未动（离线）。

## 边界

- 朝向未定：1280×1024 vs 1024×1280（平 fill 不可分；musa 默认 1280×1024，暂从之，待 stride 证据）。
- 步长：span 恰等式 ⇒ 行连续（无填充）；若他样本 span 超出，即为 stride 证据。
- 3841 常量头全零：本路径无表面描述符；他路径若有非零头，几何可直读——留口。
- 颜色字序（`ff0000ff` 的通道义）未定；translator 原样搬运像素字即可，无需解释。
- 转储二进制（5MB）未入库；本报告数字即证据（首字节/相位/双尺寸算式）。
